# Suggested Commands — minhavenda-frontend (Windows)

## Run dev server
```
pnpm dev
```

## Build
```
pnpm build
```

## Lint
```
pnpm lint
```

## Install deps
```
pnpm install
```

## Notes
- Use `dir` instead of `ls` on Windows CMD, or `ls` in Git Bash/PowerShell
- Project root: E:\code\minhavenda-frontend
